# Samford Run
Samford Run was a game made while at university, created in Unity. It is a free roam, Subway Surfer meets Crossy Road kind of game that was set on the campus of Samford University. Your objective was to get class on time, avoiding obstacles along the way. You must run, otherwise you'll be late!

![SamfordRun (1)](https://github.com/user-attachments/assets/e8c6b248-07fa-46c7-a4df-0c004cc9e0f8)

The game itself never saw a release outside of the university course it was made for, but the prototype still met the basic premis for the game.
